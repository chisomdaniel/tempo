# Tempo

## What the App Does

Tempo is a mobile-first productivity and time-tracking application that helps users understand how they spend their time.

Users can:

- Create and manage tasks
- Start focus sessions with custom durations
- Pause, resume, and stop active sessions
- Track breaks and interruptions
<!-- - Categorize activities (Work, Learning, Fitness, etc.)
- View productivity analytics and behavioral insights -->

### Problem It Solves

Many productivity tools focus on planning tasks but provide little visibility into how time is actually spent.

Tempo solves this by tracking real execution, helping users:

- Build better focus habits
- Understand productivity patterns
- Reduce time wastage
- Make data-driven improvements to their daily routines

## Why We Chose React

React was chosen because it provides:

- A component-based architecture that promotes reusability and maintainability
- Efficient UI updates through its virtual DOM
- Strong ecosystem support and community adoption
- Excellent tooling and developer experience

## How to Run the Project Locally

### Prerequisites

- Node.js (v22+)
- npm

### Installation

```bash
git clone <repository-url>
cd tempo
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
